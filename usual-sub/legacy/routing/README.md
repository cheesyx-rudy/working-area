# LIKVID VPN — Happ routing

Этот каталог публикует профиль маршрутизации отдельно от списка прокси.

- `LIKVID-RU-WHITELIST.JSON` — редактируемый профиль.
- `LIKVID-RU-WHITELIST.DEEPLINK` — ссылка Happ для добавления и активации профиля.

Логика:
- По умолчанию трафик идёт через VPN.
- `geosite:whitelist` и `geoip:whitelist` — напрямую.
- `geosite:category-ru` и `geoip:direct` — напрямую, чтобы обычные российские сервисы тоже по возможности шли без VPN.
- Остальной трафик — через VPN.
- Рекламные домены, торрент-категория и Windows spyware-категория блокируются.

Геобазы берутся из проекта RoscomVPN Routing, так как в нём используются категории `whitelist` и `direct`, необходимые этому профилю.

Важно: это отдельный профиль Happ. Он не добавляется строкой в `proxies.txt`, чтобы не ломать совместимость обычной подписки. Профиль нужно импортировать в Happ отдельно. Наличие категории в правилах не гарантирует доступность сервиса в конкретной сети/операторе; проверяйте после импорта.
